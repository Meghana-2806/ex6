# Personal Portfolio Website

A responsive personal portfolio website developed using HTML, CSS, JavaScript, and Bootstrap 5.

## Features
- Home and About Me sections
- Education and Skills
- Projects showcase
- Contact form with validation
- Responsive design
- Light and dark theme toggle

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## How to Run
1. Download and extract the project ZIP file.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, open the folder in Visual Studio Code and run `index.html` using Live Server.

## Folder Structure
```text
Personal_Portfolio_Website/
├── index.html
├── README.md
├── assets/
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Customization
Update the personal information, education, skills, projects, email address, and social media links in `index.html`.

## Contact Form
The contact form uses JavaScript validation and opens the default email application to send messages. No backend is required.
